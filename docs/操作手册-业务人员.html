3.1 场景一：新项目启动 — 配置岗位标准

当需要启动新的数据采集项目时，管理员需要先配置好岗位标准。

1 创建新项目
  1. 点击左侧菜单"项目管理"
  2. 点击蓝色"新建项目"按钮
  3. 填写项目信息：项目名称（如"动作捕捉演员-2026春季"）、项目描述、负责人
  4. 点击"保存"按钮
2 创建岗位
  1. 在项目管理页面，点击对应项目下的"创建岗位"按钮
  2. 填写基本信息：岗位名称、岗位描述、工作地点、薪资范围
  3. 点击"下一步"继续配置
3 画像配置

此配置决定了AI如何识别候选人技能

3.2 场景二：日常招聘 — 搜索与筛选候选人

日常招聘工作中，需要批量导入简历并进行智能筛选。

1 导入候选人简历
  1. 点击左侧菜单"候选人搜索"
  2. 点击蓝色"导入简历"按钮
  3. 选择文件格式：.md .txt
  4. 上传简历文件
  5. 点击"开始分析"按钮
2 选择目标岗位
  1. 在筛选区域选择对应的岗位
  2. 系统会自动显示该岗位的评分标准
  3. 可以按项目、状态等进一步筛选
3 查看AI评分结果
候选人基本信息
  • 姓名、联系方式、工作经验
  • AI综合得分：85分
  • 评级：B+档
  • 匹配关键词：数据标注、团队协作、学习能力强
  • 缺少关键词：AI训练经验

技能熟练度8025%20
团队合作能力8520%17
学习能力8515%13

4 筛选和排序

排序方式

  • 按得分降序
  • 按经验年限
  • 按技能匹配度

筛选条件

  • 评级范围 (A/B+/B/C/D)
  • 得分区间 (0-100分)
  • 工作经验年限
  • 特定技能标签
5 添加到入围名单
  1. 选择合适的候选人（可多选）
  2. 点击"添加到入围"按钮
  3. 填写推荐理由
  4. 确认添加
6 导出评估报告
  1. 选择要导出的候选人
  2. 点击"导出报告"按钮
  3. 选择导出格式：PDF 完整报告 / PNG 缩略图
  4. 点击"确认导出"

💡 操作技巧

  • 可以使用搜索框快速查找特定候选人
  • 批量操作可以提高工作效率
  • 建议定期更新岗位配置以提高匹配准确性

3.3 场景三：候选人推进 — 入围与外联

经过AI初步筛选后，需要对入围候选人进行进一步联系和推进。

1 查看入围名单
  1. 点击左侧菜单"入围名单"
  2. 查看所有入围候选人列表
  3. 可以按状态、时间、岗位等筛选
2 查看候选人详情
  1. 点击候选人姓名查看详细信息
  2. 查看完整评估报告：基本信息、AI评分和各维度得分、匹配和缺少的关键词分析、推荐理由
3 联系候选人
  1. 在候选人详情页面，点击"推进"按钮
  2. 选择联系方式：邮件联系 / 电话联系 / 微信联系
  3. 填写联系理由：参考AI评分结果 + 结合岗位需求 + 个性化建议
  4. 点击"发送联系"
4 发送面试邀请
  1. 对于合适的候选人，选择"发送面试邀请"
  2. 填写面试信息：
    • 候选人邮箱：必填，用于发送邀请邮件
    • 面试模板：必填，从下拉列表中选择（会按岗位匹配排序，显示题数和时长）
    • 面试链接：系统自动生成，候选人可进入AI面试
  3. 点击"发送邀请"
5 跟踪联系状态
  1. 更新候选人状态：已联系 / 已回复 / 已安排面试 / 已拒绝
  2. 记录联系结果和反馈
  3. 设置后续跟进时间

⚠️ 注意事项

  • 外联邮件使用mailto协议，会打开本地邮件客户端
  • 建议结合AI评分结果和实际需求进行判断
  • 及时更新候选人状态，避免重复联系

3.4 场景四：AI面试管理

需要对入围候选人进行AI面试，标准化评估流程。

1 创建面试模板
  1. 点击左侧菜单"面试配置"
  2. 点击"+ 新建面试模板"按钮
  3. 选择关联岗位（下拉选择已创建的岗位）
  4. 设置面试基本信息：模板名称、面试时长（30分钟）、面试官

添加面试问题：

专业技能评估

提问：请详细介绍您在数据标注方面的经验，包括使用过的工具和方法

时限：5分钟 | 评分：技术深度、方法规范性、经验丰富度

情景测试

提问：如果在项目中需要与其他成员密切合作，您会如何确保沟通顺畅？

时限：3分钟 | 评分：沟通能力、团队意识、问题解决

职业规划

提问：您未来3-5年的职业发展规划是什么？为什么选择这个岗位？

时限：3分钟 | 评分：目标明确度、与岗位匹配度、发展潜力

6. 点击"保存模板"

2 管理面试模板
  • 查看所有模板列表
  • 编辑或删除现有模板
  • 设置模板状态（启用/禁用）
3 开始面试
  1. 点击左侧菜单"面试管理"
  2. 选择面试模板 → 选择待面试候选人 → 点击"开始面试"
  3. 按照面试流程进行：提问问题 → 记录回答 → 评分记录
4 面试结果管理
面试评分
  • 总体评分：88分 评级：B+档
  • 各维度得分：专业技能 90分 | 沟通能力 85分 | 团队协作 90分 | 发展潜力 85分
AI面试总结
  • 匹配优势: 数据标注经验丰富，团队协作能力强，学习意愿高
  • 待改进: AI相关经验不足，需要进一步培训
  • 推荐建议: 强烈推荐录用，建议安排实操培训
5 审批流程
  1. 在"评价中心"查看所有面试结果
  2. 审核评估结果的准确性
  3. 批准或拒绝面试结果
  4. 更新候选人最终状态

📋 操作规范

  • 面试问题应结合岗位需求设计
  • 评分标准要客观明确
  • 定期检查和优化面试模板

3.5 场景五：团队管理

管理员需要管理团队成员权限和系统配置。

1 邀请团队成员
  1. 点击左侧菜单"设置" → "团队管理"
  2. 点击"邀请成员"按钮
  3. 填写成员信息：邮箱地址、姓名、角色权限（从下拉选择）
  4. 点击"发送邀请"
2 角色权限管理
管理员 (Admin)
  • 所有系统功能权限
  • 团队成员管理
  • 系统配置管理
  • 数据导出权限
招募专员 (Recruiter)
  • 候选人管理
  • 面试流程管理
  • 数据查看和导出
  • 无法修改系统配置
面试官 (Interviewer)
  • 面试执行
  • 面试结果记录
  • 候选人查看
  • 无法修改配置和系统设置
查看者 (Viewer)
  • 仅查看权限
  • 无法进行任何操作
  • 可查看基本数据
3 配置AI模型
  1. 点击"设置" → "AI模型"
  2. 点击"添加AI提供商"按钮
  3. 配置AI服务：选择AI服务商（OpenAI、Claude等）、输入API密钥、设置模型参数
  4. 点击"保存配置"
4 管理通知设置
  1. 在"设置" → "通知管理"中配置
  2. 设置通知类型：新候选人通知、面试提醒、审批通知、系统更新通知
  3. 选择通知方式：邮件通知 / 系统内通知 / 短信通知（如配置）

3.6 场景六：员工档案管理

  2. 查看4张统计卡片：在职人数 平均绩效 留存天数 培训均分
  3. 使用状态筛选按钮筛选（全部/入职中/试用期/正式/辞退/离职）+ 搜索框按姓名或邮箱搜索

  3. 点击「保存」
3 管理绩效记录

  2. 查看该员工的绩效记录列表（按周期排序）
  3. 点击「添加绩效」添加新记录：绩效周期（如 2026-Q1）、绩效分数、各维度得分（维度名/分数/备注）、优势/不足

  4. 点击「新建模型」或「AI推导」

3.7 场景七：短信模板管理（管理员）

管理员需要配置腾讯云短信模板，供招聘专员在发送短信时选择使用。

  1. 点击左侧菜单「系统管理」

2 创建短信模板
  1. 点击「新建模板」按钮
  2. 填写模板信息：

    • 参数列表（逗号分隔）：候选人姓名, 岗位名称
  3. 点击「创建模板」

4 评分体系说明

4.1 AI评分机制

EM-BOX使用多维度AI评分算法，对候选人进行全面评估：

Fit Score（适配分数）

  • 范围：0-100分
  • 计算方式：各维度得分按权重加权平均
  • 用途：衡量候选人整体适配度

Grade（评级）

评级分数区间含义
A档90-100分优秀，强烈推荐
B+档80-89分良好，强烈推荐
B档70-79分合格，推荐考虑
C档60-69分基本合格，可考虑
D档0-59分不合格，不推荐

4.2 评分维度

维度名称权重评估内容评分标准
经验对口度30%工作经验与岗位匹配度行业经验、项目经验、技能匹配
技能熟练度25%专业技能掌握程度技术深度、操作熟练度、工具使用
团队合作能力20%团队协作和沟通能力沟通技巧、团队意识、协作经验
学习能力15%学习适应和成长能力学习速度、知识迁移、成长潜力
稳定性10%工作稳定性和职业规划职业规划清晰度、稳定性、忠诚度

4.3 关键词分析

✓ Matched Keywords（匹配关键词）

候选人简历中包含的岗位所需技能，直接影响评分和推荐理由，显示为绿色高亮

✗ Missing Keywords（缺少关键词）

候选人简历中缺少的重要技能，影响评分降分因素，显示为红色标记

4.4 评分结果应用

候选人筛选

  • 按Fit Score排序
  • 结合Grade快速筛选
  • 建议70分以上

面试安排

  • A档：优先安排
  • B+档：重点安排
  • B档：根据情况
  • C档以下：重新评估

录用决策

  • 综合AI评分和面试结果
  • 考虑团队需求和实际
  • 制定个性化培养计划

5 常见问题 FAQ

5.1 候选人相关问题

Q: 候选人搜索没有结果？
A: 请检查：确认已导入候选人简历文件 / 检查是否已选择对应的岗位 / 确认简历文件格式正确（.md或.txt）/ 尝试重置筛选条件并重新搜索
Q: AI评分结果不准确？
A: 请检查：岗位画像配置是否完整 / 评分标准的权重总和是否为100% / 关键词设置是否合理 / 尝试重新分析简历文件
Q: 如何手动调整评分结果？
A: 系统不支持直接修改AI评分，但可以：在候选人详情页面添加备注 / 通过面试结果进行综合评估 / 在评价中心进行最终审批

5.2 面试相关问题

Q: 面试模板无法创建？
A: 请确保：已创建对应的岗位配置 / 选择正确的关联岗位 / 填写完整的模板信息 / 检查问题设置是否合理
Q: 面试结果如何导出？
A: 进入"评价中心" → 选择要导出的面试结果 → 点击"导出报告" → 选择导出格式（PDF或Excel）→ 点击"确认导出"
Q: 面试评分标准如何设置？
A: 建议使用1-5分制或1-10分制 / 评分标准要具体明确 / 避免主观性描述 / 可参考公司现有评价体系

5.3 系统操作问题

Q: 外联邮件发不出去？
A: 当前系统使用mailto协议，会自动打开本地邮件客户端（如Outlook、Apple Mail），预填充邮件内容，需要用户手动点击发送。如无法发送，请检查本地邮件客户端设置。
Q: 如何批量操作候选人？
A: 在候选人列表中使用复选框选择多个候选人 → 点击"批量操作"按钮 → 选择操作类型（添加入围、发送邮件、导出等）→ 确认操作并执行
Q: 数据如何导出？
A: 各页面均有"导出"按钮，支持格式：CSV、PDF、PNG。CSV适合数据分析，PDF/PNG适合打印和分享。大数据量导出可能需要等待时间。

5.4 权限相关问题

Q: 如何申请更高权限？
A: 联系系统管理员 → 说明权限需求原因 → 提供工作场景说明 → 等待管理员审批 → 权限变更后收到通知
Q: 为什么无法看到某些数据？
A: 查看者角色只能看到基础数据 / 面试官无法查看候选人详细信息 / 招募专员无法修改系统配置 / 请确认当前角色权限设置
