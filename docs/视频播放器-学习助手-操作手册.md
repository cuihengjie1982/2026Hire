# 视频播放器-学习助手 操作手册

## 功能概述

视频播放器-学习助手是培训学堂的沉浸式学习模块，为候选人提供"边听、边学、边记"的一站式学习体验。

---

## 进入方式

### 候选人端（培训门户）

1. 候选人访问 `/training/portal?cid=xxx&token=xxx`
2. 在课程卡片中找到**带有视频内容的课程**（不是纯文本课程）
3. 点击卡片展开详情
4. 点击**「进入学习」**按钮

```
路径：/training/portal/player?enrollmentId=xxx&cid=xxx&token=xxx
```

> **前提条件**：课程必须包含 `contentType: 'video'` 的章节，且课程有可播放的视频 URL。

## 标签页功能详解

### 1. AI摘要

**用途**：AI 自动分析视频内容，生成学习摘要。

**操作步骤**：
1. 进入学习页面，AI摘要标签为默认激活
2. 点击「生成摘要」按钮
3. 等待 3-5 秒，AI 返回摘要内容
4. 摘要包含：课程主题、核心知识点、学习建议

**注意**：
- 如果课程没有文字稿内容，按钮会提示"暂无文字稿内容"
- 可多次点击「重新生成」更新摘要
- AI 摘要基于文字稿内容生成，需要课程预先录制并上传文字稿

---

### 2. 文字稿

**用途**：视频的完整文字记录，带时间戳，点击可跳转到视频对应位置。

**格式要求**：
文字稿需按以下格式录入课程内容（`contentType: 'text'` 章节）：
```
00:00:00 - 欢迎参加本次培训
00:05:30 - 今天我们学习STAR法则
00:10:15 - 第一个案例分析
```

**操作**：
- **浏览**：滚动查看所有文字稿条目
- **跳转**：点击任意时间戳，视频立即跳转到该位置
- **高亮**：当前视频播放位置对应的文字稿条目自动高亮显示

**注意**：
- 如果课程没有文字稿章节，显示"暂无文字稿"
- 多章节课程可通过标签切换查看不同章节的文字稿

---

### 3. 笔记

**用途**：在学习过程中随时记录心得，自动关联当前视频时间戳。

**添加笔记**：
1. 点击右侧「笔记」标签
2. 点击顶部「添加笔记」按钮
3. 系统自动填入当前视频时间（如 `5:30`）
4. 输入笔记标题（必填）和内容（可选）
5. 点击「保存」

**编辑/删除笔记**：
- 鼠标悬停在笔记卡片上，显示编辑和删除按钮
- 点击时间戳可跳转到记录时的视频位置

**笔记持久化**：
- 笔记保存到后端数据库，刷新页面后笔记仍然保留
- 不同设备登录同一账号可同步查看笔记

---

### 4. AI问答助手

**用途**：基于视频内容和文字稿，实时回答学习问题。

**操作步骤**：
1. 点击「AI问答」标签
2. 在底部输入框输入问题（如"STAR法则是什么？"）
3. 按 Enter 或点击「发送」
4. AI 参考当前视频时间戳和文字稿内容给出回答

**显示信息**：
- 每条消息显示对应视频时间（如 `5:30`）
- AI 回复参考了哪些文字稿内容

**注意**：
- 问题会自动附带当前视频时间戳，帮助 AI 定位上下文
- 如果课程没有文字稿，AI 会基于视频主题和常识回答

## 视频播放器功能

### 基础控制

| 功能 | 操作方式 |
|------|---------|
| 播放/暂停 | 点击视频画面或播放按钮 |
| 进度跳转 | 点击进度条任意位置 |
| 快进/快退 | 点击 `-10s` / `+10s` 按钮 |
| 音量调节 | 拖动音量滑块 |
| 静音 | 点击音量图标 |
| 播放倍速 | 点击 `0.5x` / `1x` / `1.5x` / `2x` |

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| 空格键 | 播放/暂停 |
| ← / → | 快退10秒 / 快进10秒 |
| ↑ / ↓ | 音量增加/减少 |

## 快速添加笔记（快捷方式）

在视频播放区域下方，有一个「添加笔记」按钮：
- 点击后自动切换到「笔记」标签并打开笔记表单
- 时间戳自动填充为当前视频播放位置
- 无需手动切换标签

## 退出学习

点击左上角「← 返回」按钮返回培训门户课程列表页面。

## 常见问题

**Q：为什么看不到"进入学习"按钮？**
A：该课程没有视频内容章节（`contentType: 'video'`）。只有包含视频的课程才显示此按钮。

**Q：AI摘要为什么显示"暂无文字稿内容"？**
A：课程没有录制文字稿，或课程内容中缺少 `contentType: 'text'` 的章节。需要管理员在课程管理中上传文字稿。

**Q：笔记为什么没有保存？**
A：确认网络连接正常。若在 `USE_MOCK_API=true` 模式下开发，笔记仅存在内存中，刷新会丢失。

**Q：AI问答的回答不准确怎么办？**
A：AI 参考的文字稿内容可能不完整或缺失。可以尝试：1）在课程管理中补充完整的文字稿内容；2）问题尽量具体化。

---

## 管理员配置要求

要让视频学习功能正常工作，课程需要包含以下内容：

1. **视频章节**（必须）
   ```json
   {
     "sectionTitle": "第一章：STAR法则",
     "contentType": "video",
     "contentUrl": "https://your-video-url.com/video.mp4"
   }
   ```

2. **文字稿章节**（推荐，启用 AI 摘要和 AI 问答）
   ```json
   {
     "sectionTitle": "文字稿",
     "contentType": "text",
     "text": "00:00:00 - 欢迎参加本次培训\n00:00:30 - 今天我们学习STAR法则..."
   }
   ```

3. **课程难度/时长**：在创建课程时填写，便于学员了解课程规模
